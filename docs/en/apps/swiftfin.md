# Swiftfin

More about this app is coming soon.

Works on: [iPhone and iPad](#ios), [Apple TV](#apple-tv).

!!! tip "Slow or choppy playback? Set the bitrate to Maximum"

    Some Rezflix users noticed slow playback in Swiftfin. The fix is quick: open the Swiftfin
    settings, go to **Playback Quality** > **Bitrate**, and set it to **Maximum**.

### Good to know { #ios-good-to-know }

!!! warning "No downloads yet"

    Swiftfin cannot download movies and shows for offline watching yet. If you need downloads,
    use [Jellyfin Mobile](jellyfin-mobile.md#ios) instead.
